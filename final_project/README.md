# Нобелевские лауреаты

Финальный проект по Python: обработка данных Nobel Prize API и анализ лауреатов.

## Запуск

```bash
python -m pip install -r requirements.txt
jupyter notebook laureates_countries_task.ipynb
```

Откройте ноутбук из этой папки и выполните **Kernel -> Restart & Run All**.
Для загрузки данных нужен доступ к https://api.nobelprize.org. Вспомогательные функции и конфигурации находятся в `.py`-файлах рядом с ноутбуком.

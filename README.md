# OMD — домашнее задание по Python

Пять независимых задач на работу с коллекциями и обработку данных.

## Требования

- Python 3.8 или новее.
- Сторонние зависимости не требуются.

## Запуск

Из корня репозитория запустите любую задачу отдельной командой:

```bash
python task_1.py
python task_2.py
python task_3.py
python task_4.py
python task_5.py
```

Каждая программа использует исходные данные из условия задачи и выводит
результаты всех требуемых вычислений в консоль.

## Содержание

- `task_1.py` — сравнение ассортимента двух складов.
- `task_2.py` — подсчёт поисковых запросов.
- `task_3.py` — анализ доставленных и возвращённых заказов.
- `task_4.py` — анализ выручки и возвратов по дням.
- `task_5.py` — средние оценки товаров и доля низких отзывов.
